# StoryDesk

StoryDesk е Django уеб приложение за организиране на журналистически материали, теми, източници, бележки и редакционни задачи.

## Основни функционалности

- Създаване и управление на журналистически материали
- Организиране на теми
- Добавяне на източници и бележки
- Управление на редакционни задачи
- Филтриране и сортиране на материали
- Редактиране и изтриване на материали

## Технологии

- Python
- Django
- SQLite
- HTML и CSS

## Инсталация и стартиране

Необходими са инсталиран Python и Git, ако клонирате хранилището.

1. Клонирайте проекта и влезте в директорията му:

   ```bash
   git clone https://github.com/78ycnmgy55-droid/storydesk.git
   cd storydesk
   ```

2. Създайте и активирайте виртуална среда на macOS/Linux:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Инсталирайте зависимостите:

   ```bash
   pip install -r requirements.txt
   ```

4. Създайте таблиците в базата данни:

   ```bash
   python manage.py migrate
   ```

5. Стартирайте локалния сървър:

   ```bash
   python manage.py runserver
   ```

6. Отворете `http://127.0.0.1:8000/` в браузъра.

## Структура на проекта

- `stories` — теми и журналистически материали
- `research` — източници и бележки
- `planning` — редакционни задачи
- `config` — настройки и URL конфигурация
- `templates` — общи HTML шаблони

## База данни

Проектът използва SQLite за локална разработка. Командата `python manage.py migrate` създава необходимите таблици.

## Разработка

Преди работа активирайте виртуалната среда. За проверка на Django конфигурацията изпълнете:

```bash
python manage.py check
```

## Модели и връзки

- `Topic` — теми за журналистически материали.
- `Story` — материали, свързани с тема и с множество източници.
- `Source` — източници на информация.
- `Note` — бележки, свързани с материал.
- `Task` — редакционни задачи, свързани с материал.

Приложението използва връзки ForeignKey и ManyToManyField.
Формите използват етикети, помощни текстове и валидация.
Формата за задачи включва и поле само за преглед.

## Тестове

Проверка на конфигурацията:

python manage.py check
python manage.py test

Тестове за приложението с материали и теми:

```bash
python manage.py test stories
```
