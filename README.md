# StoryDesk

StoryDesk е Django уеб приложение за организиране на журналистически материали, теми, източници, бележки и редакционни задачи.

## Основни функционалности

- Създаване и управление на журналистически материали
- Организиране на теми
- Добавяне на източници и бележки
- Управление на редакционни задачи
- Филтриране и сортиране на материали
- Редактиране и изтриване на материали

## Технологии

- Python
- Django
- SQLite
- HTML

## Инсталация и стартиране

1. Клонирайте проекта или изтеглете файловете.
2. Създайте и активирайте виртуална среда.
3. Инсталирайте необходимите зависимости.
4. Изпълнете миграциите.
5. Стартирайте development сървъра.

```bash
python -m venv .venv
python manage.py migrate
python manage.py runserver
```

Ако използвате виртуална среда, активирайте я преди командите за Django. Ако проектът има `requirements.txt`, инсталирайте зависимостите с `pip install -r requirements.txt`.

## Структура

- `stories` — теми и журналистически материали
- `research` — източници и бележки
- `planning` — редакционни задачи

## База данни

По подразбиране проектът използва SQLite за локална разработка.
